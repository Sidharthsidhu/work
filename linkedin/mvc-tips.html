1

Keep controllers thin

Take the request, hand it off. Business logic lives in services you can test.

if (!ModelState.IsValid)
    return View(vm);
_orders.Create(vm); // service
return RedirectToAction("Index");
2

ViewModels, not entities

The view gets only the fields it needs. No over-posting bugs.

public class CustomerEditVm {
  public int Id { get; set; }
  public string Name { get; set; }
} // no IsAdmin here
3

Anti-forgery on every POST

One attribute protects your forms from CSRF. Easy to forget.

[HttpPost, ValidateAntiForgeryToken]
public ActionResult Edit(...)

@* in the form *@
@Html.AntiForgeryToken()
4

Always validate on the server

Client-side checks are for the user. Server-side checks are for your data.

[Required, StringLength(100)]
public string Name { get; set; }

if (!ModelState.IsValid) ...
5

Go async for I/O

Free up threads while you wait on SQL Server or an external API.

public async Task<ActionResult> Index()
{
  var list = await _db.Orders
      .ToListAsync();
  return View(list);
}
