Git for everyday work

10 Git commands
I use every day

Learn these 10 first. Look the rest up when you need them.
git
1
git status

What changed?

Run it before every other command.

2
git diff

Show the exact changes

Line by line, before you commit.

3
git add file.cs

Stage a file

Pick what goes into the next commit.

4
git commit -m "msg"

Save a snapshot

Write a message future you will understand.

5
git pull

Get the team's changes

Do it before you start work.

6
git push

Share your commits

Sends your branch to the remote.

7
git switch -c feature

New branch

One branch per feature or fix.

8
git log --oneline

Short history

One line per commit, easy to scan.

9
git stash

Park unfinished work

Bring it back with git stash pop.

10
git restore file.cs

Undo local edits

Careful: uncommitted changes are gone.
