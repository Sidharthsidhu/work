LINQ cheat sheet
10 methods, 1 list

Every example works on the same list: List<Order> orders
.NETC#

Where

Keep items that match

orders.Where(o => o.Total > 1000)

Select

Pick or reshape fields

orders.Select(o => o.CustomerName)

OrderBy

Sort (ThenBy for a 2nd key)

orders.OrderByDescending(o => o.Date)

FirstOrDefault

First match, or null

orders.FirstOrDefault(o => o.Id == id)

Any

Is there at least one?

orders.Any(o => o.Status == "Late")

Count

How many match?

orders.Count(o => o.IsPaid)

Sum

Add up a number field

orders.Sum(o => o.Total)

GroupBy

Bucket items by a key

orders.GroupBy(o => o.CustomerId)

Distinct

Remove duplicates

orders.Select(o => o.City).Distinct()

ToList

Run the query now

orders.Where(...).ToList()
