# Dev_oopss website

A one-page site for the Dev_oopss crew: the six of us, our trips and staycations, and a countdown to the next one.

## View it

Open `index.html` in any browser. You don't need to install anything.

## Make it yours

Open `index.html` and find the `EDIT THIS PART` block near the bottom:

- `INSTAGRAM_URL`: link to the group's Instagram page
- `crew`: each person's name, a fun role, an emoji and a colour
- `trips`: title, place, date (`YYYY-MM-DD`), emoji, colour and a short note

Trips dated today or later show as **Upcoming**, and the nearest one gets the countdown. Older trips show as **Done**.

## Put it online (free)

Push this repo to GitHub, then go to **Settings → Pages** and pick the branch. The site will be at
`https://<username>.github.io/<repo>/devoopss-website/`.
