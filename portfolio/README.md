# Sidharth K — Portfolio

Personal portfolio site. Plain HTML/CSS/JS, no build tools needed.

- Edit content in `src/page.html`, then run `./build.sh` to regenerate `index.html`.
- Open `index.html` in a browser to preview.

## Host it free on GitHub Pages
1. Put `index.html` at the root of a repo named `<your-username>.github.io` (or any repo).
2. Repo **Settings → Pages → Deploy from a branch**, pick the branch and folder.
3. The site goes live at `https://<your-username>.github.io/`.
